Installation and quick start

Install an audited wheel in a virtual environment or pipx. Configure existing RTL-SDR command-line tool paths in a private config.local.toml using config.example.toml. Keep one RF Atlas process in charge of your receiver.

rf-atlas --version
rf-atlas doctor --skip-receiver
rf-atlas doctor
rf-atlas app --open-browser

Doctor performs at most two finite sample acquisitions. A detected receiver with zero samples fails the delivery check. Review USB passthrough, permissions and competing applications manually; RF Atlas never changes infrastructure automatically. The app binds to loopback; use serve --port 8766 if the default port is occupied.

Start exploring and keep an inventory

Explore provides Quick, Full and Smart survey controls. A fresh installation starts idle. Choose an antenna and explicit manual gain. Signals displays private channels and history. Coverage shows what was actually visited; non-detection does not establish an empty band or continuous occupancy.

Tune & Monitor

Select a signal and choose Tune & Monitor. Monitoring pauses discovery and shares the receiver lock. AM, NFM, WFM, USB, LSB and CW modes support browser audio with a user gesture. Gain, filtering, squelch, fine tuning and volume remain explicit controls. Audio is not recorded by default. Live playback is currently blocked by the receiver's sample-delivery failure.

Analog/digital classification and machine learning

DSP remains the default. A waveform family is a hypothesis from finite I/Q measurements. RDS metadata can coexist with analog FM. Frequency allocations provide context, never protocol proof.

rf-atlas ai-train
rf-atlas ai-infer recording.cu8

Enable AI classification in Settings only after locally training the optional CPU ridge model. JSON weights and the adjacent SHA256 are checked before inference. No framework, external checkpoint or model code is downloaded. The model uses 28 RF measurements; scores are uncalibrated. Synthetic holdout family accuracy was 62.5%, while historical two-family real RF accuracy was 0%. DSP was 70.6% on that same narrow real set. AI disagreement is shown separately and never overwrites verified protocols.

Signal Lab and digital demodulation

Signal details include spectrum, waterfall, amplitude, phase and frequency plots for retained recordings. Advanced controls expose bounded investigation recipes. OOK, 2FSK, 4FSK, BPSK and QPSK diagnostic demodulation supports isolated rectangular waveforms at an explicit baud hypothesis.

rf-atlas demodulate recording.cu8 --mode 4FSK --baud 4800

Carrier/timing recovery produces candidate symbols and natural-binary bits with relative margins. PSK phase and bit polarity remain unresolved. This interface does not claim generic GMSK, QAM, pulse shaping or framing. Automatic investigation permits one measured ASK/FSK run-length hypothesis; failed attempts remain informative.

Error correction and message decoding

CRC detects errors; it does not correct them. The selected DMR CSBK path uses unique Golay slot decoding within three bit errors and bounded BPTC syndrome correction, followed by a mandatory CSBK CRC. Correction operations are not the true channel error count.

A common frame record includes decoder version, source checksum, sample position, frequency, synchronization, checksum and correction evidence. Only already validated selected protocol frames become structured metadata. The detail viewer shows retained fields and validation status. Arbitrary candidate bits and failed-CRC frames are never messages. AX.25 UI/F0 metadata is supported; APRS application text semantics are not claimed.

Privacy and troubleshooting

Keep recordings, metadata and databases private. Frame and identifier retention default off and apply independently. Raw bits may contain content or identifiers. No encryption bypass, transmitter triangulation or physical identity claims are provided. UNKNOWN can mean weak samples, conflicting evidence, unsupported framing, incompatible rate or missing decoder.

Developer API and decoder extensions

The local HTTP API provides bounded catalog/detail reads and validated receiver actions. Use the existing DecoderInput / DecoderEvidence contract for extensions, with finite managed samples and independent frame integrity. Preserve source checksums and original timestamps. Never open another receiver from an external decoder.

Testing and contributing

python -m unittest discover -s tests -v
python tools/release_check.py --tracked

Public tests synthesize IQ; private RF recordings are excluded. Test source and installed wheels separately. Split ML data by source groups and report abstentions and per-class errors. See CONTRIBUTING.md and SECURITY.md in the repository. Mathematical details and older validation reports remain in the source docs directory.
