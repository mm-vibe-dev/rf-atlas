Install locally.

Release upload and public download verification are pending GitHub authentication. No installer or package is advertised as published. This page is prepared for deployment; live hosting is not yet verified.

Windows

Windows 11 and Python 3.11+. User-scope PowerShell scripts install a SHA256-checked wheel into a separate virtual environment. Existing runtime data remains separate.

Use the installer scripts from the audited source bundle with the local wheel and its SHA256SUMS entry. Upgrade and repair create a new application slot. Uninstall removes only the marked application directory. Optional desktop shortcuts launch the application.

No drivers, administrator access or global execution-policy changes are required. Configure your already installed compatible RTL-SDR tools.

Ubuntu

Python 3.11+, pipx, either python3-venv or uv, and separately installed RTL-SDR tools. Ubuntu 24.04 and 26.04 software checks are recorded in the release validation documentation. Physical receiver validation is Windows only.

Before publication, install the audited local wheel with pipx. The validated Ubuntu 24.04 path uses pipx with its optional uv backend; the host lacks ensurepip for the default venv backend. Repository installation commands will be enabled after the public repository contains the audited release.

Upgrade with pipx using a new verified wheel; remove the application with pipx uninstall rf-atlas. Runtime data is preserved.

Check every artifact

Compare the SHA256 of the wheel or archive with the release manifest before installing. A checksum verifies bytes against that manifest; it is not a digital signature. No PyPI installation command is advertised because PyPI publication is unverified.
