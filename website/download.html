1.9.0RC1 · PRERELEASE

Install locally.

Experimental prerelease: receiver sample delivery and live endurance remain unverified. Downloaded release assets have been checked against SHA256SUMS. DSP remains the default; optional AI is experimental.

Windows

Windows 11 and Python 3.11+. User-scope PowerShell scripts install a SHA256-checked wheel into a separate virtual environment. Existing runtime data remains separate.

Download the Windows scripts archive below and verify it against SHA256SUMS. The published scripts archive requires a verified local wheel and its SHA256SUMS entry: ./install.ps1 -Wheel ./rf_atlas-1.9.0rc1-py3-none-any.whl -Sha256 <manifest SHA256> -Version 1.9.0rc1. Its automatic manifest retrieval encounters PowerShell binary-response handling; the current repository installer fixes that path. Upgrade and repair create a new application slot. Uninstall removes only the marked application directory. Optional desktop shortcuts launch the application.

No drivers, administrator access or global execution-policy changes are required. Configure your already installed compatible RTL-SDR tools.

Ubuntu

Python 3.11+, pipx, either python3-venv or uv, and separately installed RTL-SDR tools. Ubuntu 24.04 and 26.04 software checks are recorded in the release validation documentation. Physical receiver validation is Windows only.

Install a verified release wheel with pipx, or use the public Git source. The Ubuntu 24.04 Git installation was tested with the optional uv backend:

pipx install git+https://github.com/mm-vibe-dev/rf-atlas.git --backend uv
rf-atlas --version
The Git command follows main. pipx and uv must already be available; the default backend requires python3-venv.

Upgrade with pipx using a new verified wheel; remove the application with pipx uninstall rf-atlas. Runtime data is preserved.

Check every artifact

Compare the SHA256 of the wheel or archive with the release manifest before installing. A checksum verifies bytes against that manifest; it is not a digital signature. No PyPI installation command is advertised because PyPI publication is unverified.
